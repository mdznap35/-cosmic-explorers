## حدود هذه الدفعة

خط المحتوى بنية تأسيسية؛ لا يرسم وحده مشهداً قابلاً للعب. المشهد الرئيسي الحالي لن يتغير في هذه الدفعة. لا ندّعي أن الشخصيات أو الصاروخ أو عالم المريخ الجديد قد نُفّذت.

## حد التحقق المحلي

بيئة التنفيذ الحالية لا تحتوي Godot CLI. لذلك يمكن فحص المصدر وJSON هنا، لكن فحوص parsing/runtime يجب أن تعمل في GitHub Actions باستخدام Godot 4.7.2 المثبت في المشروع. نجاح CI لا يعوض اختبار الشكل والأداء على الهاتف الفعلي.
