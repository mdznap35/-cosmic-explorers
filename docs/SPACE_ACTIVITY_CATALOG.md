# كتالوج الألعاب والأنشطة الفضائية المترابطة
> نسخة تخطيطية: 1.0 — 3 نوفمبر 2026  
> كل نشاط هنا مقترح تصميمي، وليس ميزة منفذة داخل Godot.

## 1. قاعدة لا نتنازل عنها

**لا توجد لعبة جانبية غريبة عن عالم مستكشفو الكون.** كل نشاط ينتمي إلى مكان أو شخصية أو مهمة أو أداة أو اكتشاف في اللعبة. يدخل الطفل إليه من عالمه، ويفهم سبب وجوده، ويلعب، ثم يعود إلى العالم نفسه ومعه نتيجة أو صورة أو قطعة أو معرفة أو تزيين.

لا نريد لعبة مطابقة عامة بلا سياق، ولا سباق سيارات لا علاقة له بالفضاء، ولا مجموعة تطبيقات منفصلة داخل APK. حتى الألعاب الخالصة للمرح يجب أن تكون متصلة بخيال الرحلة: انعدام وزن، مسارات نجوم، تصميم مركبة، فقاعات في المختبر، موسيقى إشارات، أو زينة الغرف.

## 2. خريطة النشاط داخل العالم

| المكان | الوظيفة | أمثلة الأنشطة |
|---|---|---|
| جسر القيادة في سَنا | اختيار الوجهة ومتابعة الرحلات | خريطة المدارات، اتصالات مرقاب، محاكاة الملاحة |
| ورشة سليم | بناء وإصلاح وتجريب | CubeSat، الروفر، توصيل وحدات الطاقة |
| مختبر مرقاب | التجربة وتحليل العينات | فرز الأدلة، العدسات، الطيف، الجاذبية |
| مرصد ريم | التصوير والملاحظة | الكسوف، الكوكبات، البحث عن الأجرام |
| ركن لولو | الاستكشاف اللطيف والأسرار | مسارات الأنابيب، آثار مخفية، ترتيب القطع |
| المعرض | عرض ما جمعه الطفل | ألبوم الصور، البطاقات، نماذج المركبات |
| المناطق الكوكبية | مهام قصيرة مرتبطة ببيئة كل جرم | الروفر، الفوهات، الجليد، الحلقات |
| صالة التدريب | ألعاب قصيرة قبل الرحلة | محاكاة انعدام الوزن، قيادة المركبة، ألغاز الاتجاه |

## 4. كيف نجعل كل لعبة جزءاً من اللعبة الكبرى؟

كل نشاط يجب أن يمر بهذه الحلقة:

1. **دعوة داخل العالم:** شخصية أو لوحة أو اكتشاف يقدم سبب النشاط.
2. **تعليمات مرئية قصيرة:** صورة أو حركة توضيحية؛ لا نعتمد على قراءة فقرة.
3. **فعل مباشر:** لمس أو سحب أو تدوير أو قيادة أو ترتيب.
4. **نتيجة مرئية:** تغيير في العالم أو ظهور اكتشاف أو نجاح التجربة.
5. **أثر محفوظ:** بطاقة أو صورة أو جزء بناء أو زينة أو تقدم مهمة.
6. **رجوع طبيعي:** زر واضح يعيد الطفل إلى الغرفة أو المنطقة التي جاء منها.

لا يجب أن يعطي كل نشاط نقاطاً. قد يكون الأثر صورة جميلة أو قطعة ديكور أو فتح أداة أو مجرد نتيجة ممتعة. لا مؤقت قاسياً ولا خسارة عند المغادرة.

## 5. أول حزمة تنفيذية للألعاب الجانبية

لا ننفذ 24 نشاطاً دفعة واحدة. نبدأ بأربعة أنماط مختلفة حتى نثبت إطاراً قابلاً لإعادة الاستخدام:

### الدفعة الأولى
- ACT-01 ابنِ قمرك المصغر: سحب وتركيب وتجربة نتيجة.
- ACT-06 رسالة من مرقاب: ألغاز مسارات وإشارات.
- ACT-11 بعثة الروفر الحمراء: قيادة ومسح وتصوير.
- ACT-20 متاهة انعدام الوزن: فيزياء مرحة وتحريك أجسام.

هذه الأربعة مختلفة فعلاً: بناء، ألغاز، تحكم ثلاثي الأبعاد، وفيزياء خفيفة. كما أنها مرتبطة بالورشة والجسر والمريخ وصالة التدريب.

### الدفعة الثانية
- ACT-12 مصور المرصد.
- ACT-15 ماذا نعرف؟
- ACT-18 استوديو سَنا.
- ACT-21 صندوق الأسرار.

### الدفعة الثالثة
- ACT-04 مسار الطاقة الشمسية.
- ACT-09 خريطة النجوم.
- ACT-14 عدسة مرقاب.
- ACT-24 حديقة المحطة.

يضاف النشاط عندما تكون هناك منطقة أو مهمة تحتاجه، لا لمجرد زيادة العدد.

## 6. بنية تقنية موحدة للأنشطة

كل نشاط يعرّف كبيانات، مع مشهد مستقل ومنطق صغير واضح:

- activity_id ثابت.
- عنوان وشرح عربيان قصيران.
- المكان الذي يطلق منه.
- الشخصية أو الأداة المرتبطة به.
- نوع التحكم: tap / drag / rotate / joystick / sequence.
- زمن الجلسة المتوقع كإرشاد غير ملزم، وليس عداداً تنافسياً.
- متطلبات الفتح.
- أحداث التقدم التي يرسلها إلى InteractionRouter.
- نتيجة قابلة للحفظ.
- مكافأة اختيارية أو أثر في الألبوم.
- مسار رجوع مضمون.
- اختبار يثبت بدء النشاط والخروج منه وحفظه وإعادة فتحه.

ينبغي أن يطلق ActivityLauncher النشاط ويعيد اللاعب إلى المشهد السابق دون إعادة تشغيل غير ضرورية أو فقد التقدم.

## 7. معايير قبول النشاط

- [ ] له ارتباط واضح بمكان أو شخصية أو مهمة في عالم الفضاء.
- [ ] يمكن فهم أول فعل دون شرح طويل.
- [ ] يعمل باللمس على شاشة هاتف.
- [ ] لا يتطلب اتصالاً بالشبكة.
- [ ] لا يكرر ميكانيكية نشاط آخر مع تغيير اللون فقط.
- [ ] يملك زر رجوع/إغلاق واضحاً.
- [ ] لا يخسر الطفل تقدمه عند الخروج.
- [ ] يرسل أحداثاً معروفة فقط إلى نظام المهمات.
- [ ] لا يكرر المكافأة غير القابلة للتكرار عند الإعادة.
- [ ] لا يقدم الخيال كحقيقة علمية.
- [ ] له اختبار آلي وسموك للمشهد، ثم تجربة يدوية على Android إذا كان بصرياً أو لمسيّاً.

## 8. ممنوعات تصميمية

- لا ألعاب جانبية لا علاقة لها بالفضاء أو بالشخصيات أو بالسفينة.
- لا تكرار لعبة المطابقة عشر مرات بتغيير الصور فقط.
- لا مراحل تعتمد على السرعة وحدها أو العقوبة.
- لا نصوص طويلة توقف اللعب.
- لا روابط خارجية قابلة للنقر داخل تجربة الطفل.
- لا نسخ لشاشات NASA أو ألعاب تجارية أو شخصيات معروفة.
- لا نعلن عن نشاط على أنه موجود قبل أن يصبح مشهداً يعمل داخل اللعبة.
