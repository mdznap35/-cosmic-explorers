# Echo of Mars — Visual Foundation v1

## Purpose

This increment replaces the flat Mars floor and box-wall horizon with a shared, deterministic, low-poly landscape generator used by both the Echo of Mars story slice and the standalone rover survey. It is a visual foundation, not a claim that the final art pass or device acceptance is complete.

## What changed

- A generated 32 × 32 terrain grid with subtle height variation and vertex-colour material.
- Five faceted, layered mesa formations with deterministic silhouettes and visible sediment bands.
- Six small boulder clusters (18 stones) placed around the survey area.
- A warm sun disc and a shared procedural Mars atmosphere with restrained distance fog.
- The same terrain builder is called by the story slice and rover scene so both share one visual language.
- A headless Godot test checks the terrain mesh, surface count, mesa count, boulder count, and atmosphere setup.

## Reuse and licensing

No new third-party archive, plugin, or code dependency is added. The landscape geometry is generated by original project code. Existing pinned KayKit Space Base Bits models remain optional scene dressing, staged by the existing GitHub Actions workflow from the already-recorded CC0 source commit.

## Performance choices

- One terrain mesh surface and one vertex-colour material.
- No GDExtension, runtime download, external shader package, or texture dependency.
- Faceted terrain and mesa geometry is built once when the scene is initialized.
- The builder creates 18 decorative boulder mesh instances; if device profiling shows this is too expensive, the next optimization is to merge them into one MultiMesh without changing survey logic.
- Android frame pacing, memory, and thermal behaviour still require measurement on a physical device.

## Acceptance gates

1. Godot 4.7.2 headless project import succeeds.
2. The new landscape test passes.
3. Existing rover and Echo of Mars integration tests pass.
4. The standalone Echo of Mars Android APK exports successfully.
5. Visual composition, touch usability, and performance are reviewed on a physical Android device before the art pass is marked device-verified.

## Explicit limits

This increment does not produce final character models or rigs, animated dust, cinematic camera choreography, final audio, or a complete station interior. It also does not claim that the terrain is a scientific reconstruction of a named HiRISE or JMARS site; it is original stylized terrain with no unsupported scientific provenance.
