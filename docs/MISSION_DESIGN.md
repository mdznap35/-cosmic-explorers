# Mission design — Round 1

## Activity: Explorer Challenge

Nine short multiple-choice questions introduce the Sun and each of the eight major planets.

### Learning loop

1. Read one short question.
2. Choose from three clear answers.
3. Receive a positive response and a one-sentence explanation.
4. Continue at the child's pace.
5. See the final score and previously achieved best score.

### Child-centered constraints

- No countdown, timer, streak, leaderboard, or penalty.
- Incorrect answers reveal the correct answer with a simple explanation.
- The player can close the activity at any time.
- A completed run records local progress only.
- All question records include a NASA source URL.
- The question list is data-driven and can be localized or expanded separately from UI code.

### Persistence

The save format was advanced to version 2 while preserving version-1 discovered-planet entries. Version 2 adds mission completion count, latest score, and best score. All data remains in Godot's local `user://` directory.

### Future expansion

Later rounds can add illustrated sorting, moon discovery, spacecraft missions, and parent-led experiment cards. These are intentionally outside the first mission's small scope.
